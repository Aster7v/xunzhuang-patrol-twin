## 设计依据

使用从 GitHub 下载的 Anthropic `frontend-design` skill，原文及许可保存在 `design-skills/frontend-design/`。
来源：https://github.com/anthropics/skills/tree/main/skills/frontend-design 。此 skill 提供设计指导，不是项目运行依赖。

此次优化以 V1 自有工程为基础，不替换为第三方成品。参考项目的视觉组织、几何细节和状态展示方式，没有复制它们的业务代码。

## 紧凑视觉系统

- 雾蓝灰 `#edf2f6`：工作区底色，降低长时间观看的压迫感。
- 纸白 `#ffffff`：可操作任务与数据面板。
- 石墨蓝 `#243a4b`：正文、机器人结构件、设备对比。
- 深青绿 `#087f75`：任务操作、巡检路线和选择状态。
- 日光灰 `#aabbbd`：停车场路面，搭配浅色路缘及白色标线。
- 琥珀橙 `#b86b1d`：温度异常，与正常巡检保持色彩区分。

中文使用本机 HarmonyOS Sans SC / 思源黑体 / 微软雅黑，数字优先 DIN Alternate / Bahnschrift，离线不加载网络字体。

布局保留任务、场景、点位数据三部分，视觉重心为日间停车场。文字左对齐，数值右对齐。点位编号确实代表巡检顺序；删除每个面板的装饰性英文大写标签及场景中的宣传句。

```text
项目与导航                         时间、数据接入、平台导出
任务和巡检点      明亮的充电桩场景       采样和异常
机器人状态        路线与相机控制         图像
                  当前任务与进度
```

对照初版做出的修正：只提高曝光无法解决暗路面与暗界面之间的低对比，因此同时调整路面材质、天空雾色、环境补光和 UI 表面；设备使用圆角壳体与较低金属度，避免过度发黑。取消纯装饰的标题，增加真正有用的“导出平台配置”入口。

## 平台约束

用户只有网页编辑权限。公开前端代码证实有 GLB/GLTF 上传和 JSON 导入，不代表已经在用户账号下实测成功。
原生模型组件没有发现动画混合器或模型内部节点的位姿绑定；不把独立演示动作承诺为平台内可用功能。
主交付为静态 GLB + 使用现有组件的大屏 JSON，传感器和任务值默认显示等待。最终需导入、保存、重新打开并完成数据绑定验收。
